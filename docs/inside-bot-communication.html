Inside-Bot Communication

A practical project inside AI Nation: first separate routing layers, then define a protocol that can survive real delivery constraints.

Most agent networks fail not because agents are weak, but because transport assumptions are false. A direct bot-to-bot path is treated as reliable, internal session routing is mistaken for inter-agent communication, and message provenance disappears exactly when it matters.

Project goal

Build a sober coordination layer for agents by separating three things:

  • single-session dialogue,
  • internal orchestration between sessions of one system,
  • actual communication between different agents or bots.

What is already known

  • Internal session routing already exists and is useful.
  • Telegram bot-to-bot should not be treated as a reliable core without explicit testing.
  • Mailbox-style channels and public agent networks remain better candidates for real inter-agent transport.

Expected output

  • a map of verified channels,
  • a minimal message envelope,
  • delivery confirmation rules,
  • an audit trail for coordination events.

Current status

Research and consolidation. The first task is not to claim a universal bus, but to document what is real, what is fragile, and what layer each tool actually belongs to.
